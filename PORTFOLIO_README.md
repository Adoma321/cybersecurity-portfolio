## 🛡️ Overview

A production-ready, enterprise-grade portfolio website for **Ayman Abdullah Mohammed Al-Doma**, an ambitious Cybersecurity Analyst specializing in Network Security and GRC (Governance, Risk, and Compliance).

## ✨ Features

### 🎨 Design
- **Modern Cyber-Defense Aesthetic**: Sleek, technical, and enterprise-grade design
- **Dark Theme**: GitHub-inspired color palette (#0D1117, #161B22, #1E1E1E)
- **Accent Colors**: Cyber Blue (#0071e3) and Tech Emerald (#00E676)
- **Typography**: Inter font family for clean, professional appearance
- **Responsive**: 100% mobile-first design (Mobile SE to 4K monitors)

### 🏗️ Architecture
- **Framework**: React 18.3.1 with TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion (motion/react)
- **Icons**: Lucide React
- **Component Structure**: Modular, reusable components

```bash

```

The Vite dev server is already running in the Make environment. Changes are automatically reflected in the preview.
